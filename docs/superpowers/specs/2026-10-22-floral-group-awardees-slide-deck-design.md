## 1. Executive Summary & Intent

This project delivers a bespoke, interactive, offline-ready HTML5 presentation slide deck celebrating the **50 Group Awardees** of the **Program Health Summit 2026 (Province of Davao del Norte)**. 

Moving away from the legacy presentation template, this slide deck introduces a modern, festive, and luxurious **Floral Pink & Sky Blue** visual identity. It marries delicate cherry blossom and peony pinks with serene sky blue tones and champagne-gold gala accents, designed specifically for crisp projection on auditorium screens and celebratory viewing on mobile/desktop devices.

## 3. Visual Identity & Floral Aesthetics

### 3.1 Color Palette
* **Sky Blue Primary:** `#4BA3E3` / `#E8F4FC` (Soft celestial gradients and accents).
* **Pink Blossom Primary:** `#F06292` / `#F8BBD0` / `#FDEDF2` (Peony and sakura tones).
* **Champagne Gold Foil:** `#D4AF37` / `#C5A059` / `#FFF8E7` (Laurel leaves, card borders, award badges).
* **Deep Stage Text Color:** `#0F1E36` (Midnight Navy for optimum high-contrast readability).
* **Secondary Text Color:** `#4A5568` / `#880E4F` (Sophisticated deep berry/slate for subtitles).
* **Canvas Background:** Layered gradient from luminous pale sky blue (`#EDF6FC`) through ivory white (`#FCFCFE`) to pastel blush (`#FDF2F5`).

### 3.2 Botanical Vectors & Styling
* **SVG Floral Corners:** Hand-crafted, crisp vector illustrations of blooming blossoms, cherry flower sprigs, and gentle blue hydrangeas adorning the slide corners.
* **Award Plaque Card:** A centered, elevated card with subtle drop shadow, double gold-rimmed borders, and floral crest flourishes.
* **Badge of Honor:** A circular or ribbon-style floral seal highlighting the award sequence number (`#01`, `#02`, ..., `#50`).

### 3.3 Typography
* **Ceremonial Titles:** *Playfair Display* / *Cinzel* / *Georgia* fallback (Sophisticated, elegant serif with regal flourishes).
* **Awardee Names:** *Plus Jakarta Sans* / *Montserrat* / *Segoe UI* (Clean, uppercase, bold, high-clarity sans-serif designed for distance viewing).
* **Subtitles & Badges:** *Cinzel Decorative* / *Raleway* (Refined, letterspaced, tracked headers).

## 4. Presentation Engine & Interaction Design

### 4.1 Navigation & Controls
* **Keyboard Navigation:**
  * Forward: `Right Arrow`, `Down Arrow`, `Space`, `Page Down`, `Enter`
  * Backward: `Left Arrow`, `Up Arrow`, `Page Up`, `Backspace`
  * Jump to Start / End: `Home` / `End`
  * Fullscreen Toggle: `F` key or click Fullscreen button
  * Slide Overview Drawer: `G` key, `Esc`, or click Grid button
  * Confetti / Petal Burst: `C` key or celebratory button
* **Mouse / Touch:**
  * Floating, unobtrusive bottom navigation bar with Prev / Next arrows, Slide Counter, Grid button, Fullscreen toggle, and sound toggle.
  * Touch swipe gestures (left to advance, right to reverse).

### 4.2 Grid Overview & Instant Search Drawer
* An overlay modal displaying thumbnail cards for all 52 slides.
* Live filter input: presenters can type (e.g., "Hospital", "DepEd", "Tagum") to instantly filter and jump to any specific slide without sequential clicking.

### 4.3 Celebratory Effects & Audio Chime
* **Ambient Floating Petals:** Subtle, lightweight canvas-based drifting pink cherry blossom petals and soft sky-blue sparkles (can be toggled on/off for performance or visual preference).
* **Award Reveal Animation:** Smooth, elegant entrance animation (scale-up with fade-in and floral petal spread) on slide change.
* **Web Audio Chime (Optional):** Synthesized golden chime using the browser's native Web Audio API (no external MP3 downloads required; muted by default with an easy toggle button).

## 5. Technical Architecture & File Organization

### 5.1 Architecture
The presentation is engineered as an **offline-first, standalone web application**:
* Double-clickable `index.html`: Runs directly from the local file system in Google Chrome, Microsoft Edge, Firefox, or Safari without requiring `npm run dev` or a local HTTP server.
* Embedded SVG floral graphics: Eliminates external image link failures.
* Modular or inline structure: All logic, CSS styles, and slide data bundled cleanly with no external dependencies that require an active internet connection.

### 5.2 File Structure
```
PRESENTATION/

├── css/
```
